# 事件字典（产品交付物）

> 开发文档 §5.3 要求：事件字典与看板指标定义同一份文档、同一次评审产出。
> 本表维护「§4.2 每一个指标 → §5.2 具体字段」的双向追溯。任何字段若不再被指标或标签规则消费，必须删除。
> Schema 版本：1.0.0（与 interaction_event.schema.json 同步升版）

## 1. 标识体系（§5.1）

| 标识 | 含义 | 生成方 | 约束 |
|---|---|---|---|
| tenant_id | 租户 | 平台 | 所有数据物理隔离键 |
| user_id | 用户 | 宿主应用 | 存储时哈希/假名化 |
| session_id | 会话 | 宿主应用 | |
| turn_id | 一轮问答 | 路由服务 | 一次提问 + 一次回答 |
| trace_id | 完整执行链路 | 路由服务 | 与 turn_id 一一对应；**唯一关联键** |
| card_id | 卡片定义 | 卡片管理端 | 引用时必须携带 version |
| render_id | 一次渲染实例 | 渲染器 | 同一卡片同 turn 可多次渲染 |

## 2. 事件类型

| event_type | 触发时机 | 必填分组 |
|---|---|---|
| card_rendered | 组件渲染完成 | card, route_context |
| card_interaction_started | 用户首次操作组件 | card, payload.time_to_interact_ms |
| card_submitted | 用户完成提交 | card, payload, (group), (label_hint) |
| card_abandoned | 渲染后超时/切走未提交 | card, payload.time_to_interact_ms |
| feedback_given | 评价型组件提交 | card, payload, label_hint |
| control_invoked | 控制型组件触发 | card, payload.action |
| render_degraded | 渲染降级为纯文本 | card, payload.reason |
| card_ref_missing | 运行时引用失效卡片 | card.card_id, payload.reason |

## 3. 指标 → 字段追溯（看板 B 类洞察视角）

| 看板指标（§4.2 B） | 消费的字段 | 计算口径 |
|---|---|---|
| 组件触发分布 | card.component_type + card.trigger_source (card_rendered) | 按类型/触发方式分组计数 |
| 交互完成漏斗 | event_type 序列 (rendered → interaction_started → submitted / abandoned)，按 render_id 关联 | 各步转化率，T+1 |
| 选项选择分布 | payload.options_offered, payload.user_selection (card_submitted) | 按卡片分组的选择直方图 |
| 默认值修改率 | payload.recommended_default, payload.modified_from_default | modified=true 占比 |
| 群体决策分歧度 | group.distribution, group.participants_count | 1 - top1占比，加权熵 |
| 模型质量对比 | label_hint.target_models + polarity + route_context.selected_models | 按 label_kind 分开统计胜率/点踩率 |
| 标签产出速率 | label_hint.source + 准入结果 | 每日有效标签数按来源分组 |

## 4. 指标 → 字段追溯（看板 A 类成本运行视角）

A 类指标不消费交互事件，消费 RouteDecision / Trace（§3.4、§4.3）：

| 看板指标（§4.2 A） | 数据来源 |
|---|---|
| Token 消耗（输入/输出/思考/缓存四分） | RouteDecision.model_calls[].tokens_* |
| 金额与预算进度 | RouteDecision.total_cost + quota_usage |
| 单次会话成本分布 P50/P90/P99 | Trace.total_cost 直方图 |
| 路由分布 + 选择熵 | RouteDecision.final_model_or_aggregator |
| 聚合触发率 | RouteDecision.switch_result = aggregated 占比 |
| 快车道命中率 | RouteDecision.switch_result = fastlane 占比 |
| 延迟分布（按路径） | Trace.total_latency_ms × switch_result |
| 失败与降级次数 | span(status=error/timeout) + render_degraded + card_ref_missing 事件 |

## 5. 标签规则消费（P1 → P2）

| 字段 | 消费方 | 规则 |
|---|---|---|
| label_hint.* | 标签写入管道 | 前端事件不直接写 bank；经 清洗准入 → 候选标签池 → bank |
| payload.user_selection + group.distribution | label_polarity_map | 卡片配置定义行为→极性映射 |
| route_context.is_explore | 准入 | 探索流量单独标记，不污染质量统计 |
| route_context.ab_group | 准入 | 实验期流量按组隔离，不混入基线 bank |

## 5.1 隐式行为信号（§3.5 标签链路之三）

隐式信号复用 `feedback_given` 事件，`card.component_type = implicit.behavior`（无卡片定义，系统注入），
`label_hint.source = implicit_behavior`，置信度 0.25（低质量高覆盖）：

| payload.behavior | 极性 | 语义 |
|---|---|---|
| copy_answer | +1 | 用户复制了回答（采纳） |
| retry_with_other_model | -1 | 用户要求换模型重答 |
| interrupt | -1 | 用户中断生成（预留） |

## 6. 准入规则（§3.5 标签写入管道）

1. 同一 user_id 对同一 turn_id 的同类反馈只计一次（后到丢弃）
2. 单 user_id 单日反馈数 > 200 → 标记可疑，不自动入库
3. label_kind=preference 的标签不得写入 capability 用途的计算
4. A/B 实验流量按实验组隔离
